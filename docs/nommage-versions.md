# Règle de nommage des versions de Tɔlɔmɛ

Chaque année, Tɔlɔmɛ publie une nouvelle version dont le nom de code est celui d'une localité du Bénin. Chaque version met en avant une langue nationale.

## Critères

1. Une langue par version : chaque version annuelle met en avant une langue nationale du Bénin.
2. Un ordre fondé sur les statistiques : les langues sont classées selon leur nombre de locuteurs (RGPH4 de 2013, analysé par l'ODSEF).
3. Une alternance Sud-Nord : au premier tour, une langue du Sud est suivie d'une langue du Nord.
4. Un nom de localité : chaque version porte le nom d'une localité où la langue est largement parlée.
5. Un patrimoine à illustrer : on choisit de préférence une localité au patrimoine culturel ou naturel fort, qui sert de fond d'écran.
6. Un nom unique : un nom de localité ne sert qu'une seule fois.
7. De la neutralité : on écarte les lieux associés à une figure politique actuelle ou à un conflit récent.
8. De la transparence : la règle et l'ordre des langues sont publics.
